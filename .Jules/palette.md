## 2023-10-27 - [Enhance Keyboard Accessibility and Focus States in Popup]
**Learning:** In a Chrome Extension popup context, implementing fully accessible interactive elements requires explicit role mapping and keyboard bindings (Space/Enter). The `i18n` logic must be expanded dynamically to apply translations to A11y properties such as `aria-label`.
**Action:** When creating new custom UI components or refactoring faux buttons (e.g., `div` elements intended as buttons), ensure `tabindex="0"`, `role="button"`, `:focus-visible` styling, and appropriate localized `aria-label` tags are strictly integrated.
## 2024-05-18 - [Dynamic ARIA labels in Chrome Extension popup and options]
**Learning:** When populating dynamic DOM elements in Chrome Extension popups and option pages (such as messages from `sendMessage` or custom sliders), standard HTML attributes alone often fall short for screen readers. Using template literals to inject punctuated readable strings into `aria-label` and `title` (for truncated UI elements) significantly improves a11y. Setting `aria-valuetext` explicitly is critical when sliders represent non-linear or formatted values (like time intervals).
**Action:** When dynamically building list items or rendering custom input elements, ensure screen readers have a flattened, punctuated version of the visible text mapped to `aria-label`, and use `aria-valuetext` for custom ranges.
## 2024-10-04 - [Better Error Empty States]
**Learning:** Generic empty states ("No items") during error conditions (disconnected, logged out) are misleading. Service workers often track the actual state but fail to pass it to the UI layer. Passing state information enables rendering context-specific empty states (e.g. a lock icon for "Logged out") instead of a generic empty message.
**Action:** When working on data fetching UI components, always check if the background service has access to error states (logged out, disconnected) and ensure these are passed to the UI layer so the user receives a context-aware empty state rather than a generic one.
