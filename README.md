# VK Message Checker

Расширение для Chrome (Manifest V3), которое показывает счётчик непрочитанных сообщений VK на иконке панели инструментов и позволяет быстро открыть VK. Структура и большая часть механики (иконка, тёмная тема, уведомления, тихие часы, локализация) скопированы и адаптированы из [ya-mail-checker](https://github.com/cmrd-a/ya-mail-checker) — того же автора расширения для Яндекс.Почты.

## Статус: ядро не реализовано

**`js/vk.js` — заглушка.** В отличие от ya-mail-checker (где парсер `lite`‑инбокса Яндекс.Почты был реверс‑инжинирен из реального HAR‑захвата), для VK ещё никто не захватывал реальную разметку `vk.ru/im`. `analyzeHTML`/`analyzeMessagesHTML` сейчас всегда возвращают «неизвестно» (`-1` / `[]`) вместо того, чтобы гадать по неподтверждённым предположениям о структуре страницы.

Официальный API VK для чтения чужих сообщений (`messages.getConversations`, `account.getCounters` и т.п.) требует OAuth‑токен, выданный **Standalone**‑приложению — а такие приложения ВК больше не регистрирует. Поэтому единственный реалистичный путь — как и с Яндекс.Почтой — работать через веб‑интерфейс `vk.ru` с сессионными cookie пользователя (`fetch` с `credentials: "include"`), а не через официальный API.

### Что нужно, чтобы закончить

1. Захватить HAR (или собрать через DevTools → Network → «Copy as cURL») настоящего запроса, который отдаёт непрочитанные сообщения на `vk.ru/im` (или более лёгкой странице, если ВК её всё ещё отдаёт — например, `m.vk.com`).
2. Найти в разметке признак количества непрочитанных диалогов и, если нужно, список самих сообщений (отправитель/текст/ссылка) — так же, как `js/edition.js` в ya-mail-checker парсит `b-folders__folder__num` и `b-messages__message`.
3. Реализовать `analyzeHTML`/`analyzeMessagesHTML` в `js/vk.js` по этому образцу, добавить тесты в `tests/vk.test.js` на реальных (или максимально приближённых) фикстурах.
4. Обновить `js/background.js`, если у VK есть похожая цепочка редиректов при разлогине (сейчас `fetchResolvedMessages` делает один прямой `GET`, без цепочки — в ya-mail-checker это было нужно из-за особенностей Яндекс.Паспорта).

## Возможности (уже реализовано, независимо от парсера)

- Счётчик на бейдже иконки, цветная/серая иконка для состояний «есть сообщения» / «не авторизован», адаптация под тёмную/светлую тему панели.
- Периодическая фоновая проверка через `chrome.alarms` с настраиваемым интервалом (или «никогда»).
- Индикатор проверки (синий бейдж `…`) и понятные подсказки‑тултипы.
- Поведение по клику: меню‑попап **или** одиночный клик = открыть VK / двойной = проверить сейчас.
- Попап: аватар‑кружок с инициалом отправителя, счётчик непрочитанных рядом с заголовком, время последней проверки внизу; клик по сообщению открывает его. Показывать только непрочитанные — настраивается (по умолчанию включено).
- Мигание значка на панели при появлении новых сообщений (можно отключить).
- Звук уведомления на выбор: системный, два синтезированных тона («перезвон» / «колокольчик») или без звука.
- «Тихие часы» — на выбранный интервал времени уведомления и звук отключаются (счётчик на бейдже продолжает обновляться).
- Гибкое открытие VK: переиспользование существующей вкладки, текущая/новая/фоновая вкладка.
- Локализация интерфейса: язык выбирается **в настройках расширения** (Авто / English / Русский), а не зависит от языка браузера.

Все эти части не зависят от того, как именно устроен парсинг `vk.ru` — как только `js/vk.js` научится возвращать реальные данные, всё остальное (иконка, уведомления, попап, настройки) заработает без изменений.

## Требования

- Chrome **116+**.

## Установка (режим разработчика)

1. Открой `chrome://extensions`.
2. Включи **Режим разработчика** (Developer mode) в правом верхнем углу.
3. Нажми **Загрузить распакованное расширение** (Load unpacked) и выбери папку проекта.
4. Иконка появится на панели инструментов. Пока `js/vk.js` — заглушка, счётчик всегда будет показывать «неизвестно» (`?`).

После изменений в коде нажми «Обновить» (↻) на карточке расширения в `chrome://extensions`.

## Настройки

Открываются через меню‑попап → шестерёнка или со страницы `chrome://extensions`.

- **Язык** — язык интерфейса (Авто / English / Русский).
- **Проверка сообщений** — показывать в попапе только непрочитанные.
- **Уведомления** — показывать desktop‑уведомление, мигать значком, звук уведомления, «тихие часы» с диапазоном времени.
- **Автопроверка** — интервал фоновой проверки (от 1 минуты до «никогда»).
- **Иконка на панели** — показывать ли счётчик; меню по клику или одиночный/двойной клик.
- **Открытие VK** — сбрасывать ли счётчик при открытии, переиспользовать вкладку, куда открывать VK.

## Сборка пакета

```bash
./build.sh
```

или на Windows:

```powershell
.\build.ps1
```

Скрипт собирает `dist/vk-message-checker-<версия>.zip` только из нужных в рантайме файлов (`manifest.json`, `_locales`, `css`, `html`, `js`, `icons`).

## Структура проекта

```
manifest.json            # Манифест MV3 (service worker, action, host_permissions)
_locales/                # Переводы (en, ru) в формате chrome.i18n messages.json
icons/                   # Иконки расширения (сгенерированы процедурно, не логотип VK)
css/                     # Стили страниц (options.css, popup.css)
html/                    # Разметка страниц (options.html, popup.html, offscreen.html)
js/
  background.js          # Service worker: проверка сообщений, иконка, расписание, открытие
  vk.js                  # URL VK и парсер разметки (ЗАГЛУШКА, см. выше)
  i18n.js                # Загрузчик локали по выбору пользователя + локализация страниц
  options.js              # Логика страницы настроек
  popup.js                # Логика меню‑попапа
  offscreen.js             # Offscreen‑страница: тема браузера + синтез звуков уведомлений
tests/
  vk.test.js              # Тесты парсера (сейчас — документируют поведение заглушки)
  background.test.js      # Тесты resolveLang/isQuietHours/fetchText/checkNow
```

## Ограничения

- Парсер `js/vk.js` не реализован (см. «Статус» выше) — расширение пока не показывает реальные данные.
- Как и в ya-mail-checker, реальные действия с сообщениями (пометить прочитанным, удалить и т.п.) не планируются, пока их эндпоинты не будут найдены в реальном захвате трафика.
- Требуется активная сессия (авторизация) в VK в том же профиле браузера.
